# Fixed Header & Fixed Footer Menu

Bài thực hành tạo bố cục **Fixed Header** và **Fixed Footer**.

## Tính năng
- Menu điều hướng cố định ở **trên cùng** (`position: fixed; top: 0`)
- Footer cố định ở **dưới cùng** (`position: fixed; bottom: 0`)
- Nội dung chính có chiều cao lớn để tạo thanh cuộn demo hiệu ứng

## Cách xem
Mở file `index.html` bằng trình duyệt và cuộn trang để thấy menu + footer luôn cố định.
